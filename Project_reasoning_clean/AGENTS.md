# ข้อกำหนดในการทำงานกับโปรเจกต์นี้

## ภาษาของเอกสาร

ผู้ใช้กำหนดให้ไฟล์ `.md` ที่ใช้เป็นเอกสารอธิบาย เช่น README, เอกสารใน `docs/`, คู่มือ แผนงาน และรายงาน เขียนเป็นภาษาไทยเป็นค่าเริ่มต้น รวมถึงเมื่อสร้างหรือแก้ไขเอกสารในครั้งต่อไป เว้นแต่ผู้ใช้สั่งเป็นอย่างอื่นอย่างชัดเจน

คงชื่อไฟล์ path ชื่อ class/function, config keys, คำสั่ง โค้ด และศัพท์เทคนิคที่จำเป็นไว้ตามจริง เพื่อให้ใช้งานและอ้างอิงได้ถูกต้อง

ข้อกำหนดนี้ใช้กับเอกสารอธิบาย ไม่ใช่คำสั่งให้แปลไฟล์ prompt/template `.md` ที่เป็น input ของการทดลอง เพราะการแปลจะเปลี่ยนพฤติกรรมโมเดล และไม่ให้แก้เอกสารหลักฐานต้นฉบับใน `reference_results/` โดยอัตโนมัติ
